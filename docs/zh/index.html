•3 tools Bash · Read · Grep

一条命令。

需要 omp 18.13 或更新版本。

$ omp plugin install github:OneLastHuman/omp-compact-tools
  1. 用上面的命令安装插件。
  2. 重启 omp。
  3. 运行 /compact-tools 切换模式，或用 /compact-tools group 直接进入合并模式。
