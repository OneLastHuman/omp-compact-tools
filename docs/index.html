A display plugin for omp. Fold each call into a row, or group a run into one summary.

Display only. Tool calls, results, and model context stay the same.

The same eight calls, three ways.

The same eight tool calls shown in three modes: default boxes, one line per call, or one grouped summary. Use the mode buttons to switch.

Three ways to read the same work.

Switch modes with /compact-tools. The plugin starts in line.

•3 tools Bash · Read · Grep

One command.

Requires omp 18.13 or newer.

$ omp plugin install github:OneLastHuman/omp-compact-tools
  1. Install the plugin with the command above.
  2. Restart omp.
  3. Run /compact-tools to switch modes, or /compact-tools group to start grouped.
